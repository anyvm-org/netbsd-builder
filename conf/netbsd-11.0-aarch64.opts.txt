# wait screen text  | press key | timeout seconds
# evbarm-aarch64 sysinst answer file. Derived from the amd64 flow by hand-
# driving the live installer; the aarch64 differences from amd64 are:
#   * no "Keyboard type" menu (amd64's "English" step is gone),
#   * a main-menu step selects "Install NetBSD to hard disk",
#   * GPT instead of MBR (no MBR geometry warning),
#   * no "Bootblocks" menu (UEFI boot, not MBR bootblocks),
#   * the disk is ld4 (virtio-blk), but "Available disks" still anchors it.
#
# EVERY line must carry the third (timeout) column. build.py's waitForText()
# treats an empty timeout as "wait forever", so a single unbounded line turns
# any guest that dies mid-install into a job that spins "(no new screen text)"
# until the 6 h CI ceiling or a human kills it (2026-07-26/27 that cost a 2 h
# and a 3.5 h job on the x86_64 files). With every line bounded, a dead guest
# fails the build in minutes and rerun.yml retries it automatically.
#
# Values are generous, not tight -- a timeout here is a crash backstop, not a
# performance budget. This is a TCG (emulated) VNC+OCR build, so everything is
# slower than the amd64/KVM flow: the timeouts below are roughly double.
