# EVERY line must carry the third (timeout) column. build.py's waitForText()
# treats an empty timeout as "wait forever", so a single unbounded line turns
# any guest that dies mid-install into a job that spins "(no new screen text)"
# until the 6 h CI ceiling or a human kills it (2026-07-26/27 that cost a 2 h
# and a 3.5 h job on the 9.x file). With every line bounded, a dead guest fails
# the build in minutes and rerun.yml retries it automatically.
#
# Values are generous, not tight -- a timeout here is a crash backstop, not a
# performance budget.
